# 教学网课程导入

## 已实现的流程

Chrome打开已登录的课程页面 → 用户点击导入助手 → 从当前课程菜单发现通知、作业和课程内容入口 → 只读获取页面并解析 → 核对数量 → 使用本机临时连接码导入 → 课迹展示资料、附件链接及截止。

不要求用户手工整理JSON；手工表单/JSON仍作为补充方式保留。采集使用浏览器现有登录会话，不读取或导出Cookie，也不将登录信息交给后端。

## 使用

1. 启动课迹本地服务，在“资料收集”点击“复制导入连接码”。
2. 首次使用：Chrome扩展管理页开启开发者模式，加载项目browser-extension目录。安装本地未上架扩展需要用户明确确认。
3. 在教学网打开目标课程，点击“课迹教学网导入助手”的“采集当前课程”。
4. 核对课程名称、通知/作业/目录数量、截止冲突和待确认项，粘贴连接码，点击“确认导入课迹”。
5. 回到课迹“刷新导入结果”，按课程和类型筛选；打开目录附件、原始要求和版本历史。

连接码仅驻留服务内存，重启服务后失效。弹窗关闭后采集结果与码清空。固定接收地址为127.0.0.1:8765；扩展站点权限按Chrome规则覆盖127.0.0.1主机，程序只使用上述固定端口与路径。

## 范围与异常

- **课程通知**：标题、正文、稳定通知编号、来源页面。成功检查的空通知栏明确记录0条；缺少栏目或请求失败不能当作空栏。
- **课程作业**：要求、附件目录和截止依据。书面作业详情只读到期信息与要求；测试只GET说明页，不点击开始、创建尝试、填写或提交答案。
- **课件目录**：课次、说明、附件名称与原始链接。支持课程内容子目录，最多30页。不下载/解析附件正文，不处理课堂回放流媒体。
- **截止日期**：识别系统字段与正文，统一北京时间；日期冲突保留多个来源，并按最早候选时间提醒核对；没有明确时间留待确认。正文缺年份时以采集日期年份推定并明确标注，不把推定写成已核实事实。
- **原子性**：任一栏目读取/结构验证失败，则整个采集停止；后端再次验证三栏目覆盖、计数和同一课程关系，再事务保存。
- **更新**：同课程、来源和稳定条目编号生成同一ID；采集时间仅更新核查记录，不造成内容版本膨胀。正文/附件目录变化生成新版本，学生勾选独立保存。
- **删除**：当前保留已导入历史记录，不自动删除教学网后来撤下的资料；最近栏目计数表示当次快照，历史目录数量可能更多。

## 实现

|模块|职责|
|---|---|
|browser-extension/parser.js|纯DOM解析、来源检查、截止证据与冲突合并|
|browser-extension/collector.js|当前课程发现、同源GET、受限目录遍历、生成采集批次|
|browser-extension/popup.js|触发采集、预览计数、用户确认后传入本机|
|server/blackboard.py|三栏目计数、来源课程与核查时间验证|
|server/domain.py|资料、附件、截止证据与原有数据规则|
|server/repository.py|资料版本、学生状态和最近采集记录|
|GET /api/connector|在本机课迹页面取得临时连接码|
|POST /api/blackboard/imports|连接码验证后接收完整课程快照|

本地服务不接受任意跨域写入，连接码不写入项目文件或数据库。扩展不申请cookies、webRequest、storage权限，不定时采集；只在用户点击时获得activeTab临时权限。不读取作业提交正文、评论、成绩或隐藏表单字段。此为本地单用户方案，不是公网部署方案。

设计参考：Chrome官方[activeTab](https://developer.chrome.com/docs/extensions/develop/concepts/activeTab)及[跨来源请求](https://developer.chrome.com/docs/extensions/develop/concepts/network-requests)说明。

## 2026-11-11 真实课程验证

通过Chrome已登录会话读取测试课程三栏目及作业说明页的指定DOM区域，经扩展共用解析器生成课程清单，再用资料页JSON入口入库。结果为2条通知、7项作业、7项课件目录及7个截止项，共23条记录。首次新增23条，重复导入新增0、更新0、未变化23条。课件类型筛选显示7项，原始链接和附件链接可见。某测试作业同时保留列表两处不同日期的冲突依据。



真实课程名称、时间地点、教学网页面截图、联调快照和含真实内容的汇报PPT未纳入公开PR，由组内单独保留。本公开分支中的课程信息均为示例；实际验收结论见组内材料。
