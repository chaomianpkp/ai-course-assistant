# 课迹教学网导入助手

Chrome MV3扩展。只在用户点击时获得当前标签页的临时读取权限（activeTab + scripting），不申请教学网持久站点权限、不读取Cookie。唯一固定网络目的地为本机课迹 http://127.0.0.1:8765。

在chrome://extensions开启开发者模式，加载本目录。第一次安装须由用户确认。随后：启动课迹→在资料页复制连接码→打开教学网某门课程→点击扩展“采集当前课程”→核对数量→输入连接码并确认导入→回到课迹刷新。

采集范围为三种栏目及其课程内容子目录（最多30页），作业详情只读要求与到期字段；不点击测试开始，不访问提交动作，不采集成绩、提交正文及评论。目录附件仅采集名称/链接，不下载正文。不后台定时运行。弹窗关闭后临时采集结果清空。

DOM结构与登录不符合预期时整批中止；同课程来源稳定编号去重，内容变化保留新版本。通知为空仍记录成功检查的0条；缺少栏目或加载失败不能写成0条。截止来源冲突时保留所有证据，按最早候选时间提示核对；无明确时间保留“待确认”。
